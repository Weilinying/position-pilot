## 冻结 Contract 与实现

| kind | scope identity | 允许持久化 | 权威边界 |
| --- | --- | --- | --- |
| POSITION_PLAN_V1 | account + ticker:LONG_TERM/SWING + kind | target_budget Decimal / USD | 当前资本配置目标，独立于 Cash / 当次预算 |
| INVESTMENT_THESIS_V1 | account + ticker:LONG_TERM/SWING + kind | thesis_text | 用户背景假设，允许新证据质疑 |
| HOLDING_HORIZON_V1 | account + ticker:LONG_TERM/SWING + kind | horizon_category、可选带时区 until | 持有意图，不改 Ledger 仓位类型 |

Ticker 规范化为大写。UNSPECIFIED 不允许。三种 Intent 的 LONG_TERM / SWING 均互相独立。
同 `account + scope + kind` **最多一个 ACTIVE 和一个 PENDING，二者同时存在合法**。
Candidate 默认 24h；到期不可确认，也不进入 Context，无需后台清理才能生效。

- additive 0011 增加 identity / candidate / confirmed version 三表与 Owner / 来源复合 FK、独立唯一索引。
- Draft 不拥有 Authoritative ID / version；Service 从真实同 Owner / 同 Turn User 与成功 Assistant
  生成候选，逐字验证当前 User 依据。禁止派生字段、quantity、当前价格、tranche / trigger 等结构。
- Candidate 与 Answer / Sources / Turn completion 同 UoW，校验失败整体回滚 Assistant / Candidate。
- API 复用 Session Account。新增读取、显式 confirm / cancel；没有任意 Payload Create API 或 Mutation Tool。
  revision / base version / expiry / idempotency 在锁下重新校验；确认原子 Supersede / 新建版本。
  同 key 同内容重放返回同一版本；跨内容 key 冲突返回 409 并回滚。
- Card 展示 scope、kind、operation、字段、来源、过期时间及“不是订单”；不乐观声称生效。
  冲突重读、刷新恢复，Auth / Thread 变化后忽略陈旧响应。聊天“好”不能确认。
- 只读取 ACTIVE Confirmed Intent；删除 Thread 取消 Pending，Confirmed 仍跨 Thread 保留。
  每次从当前 Ledger 派生 `remaining_target_budget=max(target_budget-open_cost_basis,0)`，不持久化该值。
